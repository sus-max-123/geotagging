    How it works

    Three steps per business, however many photos you have.

    1

    Drop the pin

    Paste coordinates or a Google Maps link straight into the latitude box. Both fields fill in and the card's left edge lights up.

    paste 31.5204, 74.3587
    2

    Load the batch

    Hit Add photos and select the lot, or drag the folder onto the card. Rows are created for every file automatically.

    select 90 files → 90 rows
    3

    Tag and download

    Paste your keyword list in bulk, then run it. You get one ZIP, foldered per business, filenames built from the keywords.

    output gbp-tagged-photos.zip

    Questions, answered

    What the tool writes, what it does not, and where things go wrong.

    01Does Google actually rank photos by geotag?

    Not confirmed. Google has never listed photo EXIF as a ranking factor, and has at times said it strips metadata on upload. Embedding GPS, keywords, and a description is standard practice across local SEO and it costs nothing to do properly, but treat it as a supporting signal rather than a lever. Anyone promising rankings from geotagging alone is overselling it.

    02Why do photos need re-attaching after I reload?

    Browsers do not let a page hold on to files between sessions, for good reason. Business names, coordinates, keywords, and descriptions are all saved automatically and come back, so only the photos themselves need reselecting. Use Add photos and the whole batch lands in one go.

    03My iPhone photos failed. What happened?

    They were almost certainly HEIC. Most browsers cannot decode that format, so the row fails and gets outlined in red. Convert to JPEG first, or set the iPhone camera to Most Compatible under Settings, Camera, Formats. The tool flags HEIC files with a warning on the thumbnail before you run the batch.

    04Do the photos get uploaded anywhere?

    No. Decoding, resizing, EXIF writing, and ZIP packing all happen in your browser. Nothing is sent to a server, there is no account, and once the page has loaded it works with the wifi off. That is the main reason to use this over an online bulk tagger when the photos belong to a client.

    05How are the filenames and folders decided?

    Each business becomes a folder, named from the business name in lowercase with hyphens. Each file is named from that post's keywords, trimmed to 90 characters, with a number appended if two posts share keywords. Leave keywords blank and you get post1.jpg instead, which wastes the filename, so the readout warns you about empty keyword fields before you run.

    06What size and quality should I export?

    2000px at 90% is the default and suits GBP well. Google wants at least 720px, so there is plenty of headroom, and the cap keeps a 90-photo batch fast. Drop to 1600px if you are working from phone photos and want smaller files. Go to 2400 or 3000 only when the photos are genuinely detailed and the extra pixels will survive Google's own recompression.

    07Can I reuse a client list next month?

    Yes, two ways. Save list downloads a JSON file with every business, its coordinates, and all the keyword and description text, which you can import next month and just add fresh photos to. Duplicate does the same for a single business inside the current session, keeping the coordinates and clearing the keywords.
